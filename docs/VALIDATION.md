## 2026-10-27 x86 真机安装与反代测试

在完成存储快照与系统配置/应用包备份后，通过飞牛应用中心安装已发布的 x86 FPK：

- 默认扩展关闭：安装、说明页、停止/启动、卸载及重装均通过；旧 WatchCow 与旧桌面入口保持原状。
- 明确授权后启用扩展：原 WatchCow 停止，新应用接管现有入口，原生 Nginx 按预期重启一次，飞牛 HTTP/HTTPS 主页正常。
- 真实 Emby：经原 NAS HTTP 端口返回 200，页面与直连后端内容完全一致；Range 请求返回正确的 206 和字节区间。HTTPS 转发通过，但该设备证书未覆盖子域名，严格证书校验失败。
- 已安装子应用 CGI：启动页通过，访问管理路由被 403 拒绝。标题、图标、权限和其他非路由字段保持不变。
- 扩展启用后的停启：停止应用时反代返回 503，飞牛与业务后端继续正常；再次启动后反代恢复，Nginx 主进程未再次重启。
- 比对安装前后容器状态、启动时间、重启计数：业务容器未重启。

此次测试使用本机 Host/SNI 定位，尚未配置泛域名 DNS 与覆盖子域名的证书，因此不能据此声称外网端到端验收通过。旧 WatchCow 的后端协议/端口配置也会被继承，例如 HTTPS 后端被标为 HTTP 或将 RPC 接口作为网页入口，需要单独纠正原配置。

尚未验证：真实 FPK 升级、扩展模式启用后的完整卸载回退流程、ARM 飞牛硬件、实际 Emby 登录和媒体播放、用户外网 DNS/TLS、并发性能、飞牛系统更新兼容性。因此 0.1.0 仍为测试版。

启用反代需要明确设置 `WATCHCOW_R_NATIVE_EXTENSIONS=true`。这会暂停飞牛 Nginx 配置自恢复，并重启一次 Web 服务。默认安装保持关闭，安装前请阅读 README 的模式说明和迁移回退行为。

## 0.1.1 自动桌面迁移检查

- 验证飞牛入口登记中的实际 URL，而非仅检查磁盘配置。
- 测试重复同步不重装、保留原安装卷和启停状态、零退出码但含错误的 CLI 响应、安装中断后的恢复。
- 测试自定义控制脚本、额外资源操作、包标识不匹配及外部符号链接不会进入自动安装流程。
- 测试隐藏入口的空桌面目录、无端口 URL 的协议归一化，以及安装卷不可用时保留原包。
- 测试回退先恢复旧文件，再同步飞牛桌面登记。
- `go test -race ./...`、`go vet ./...`、x86_64/ARM64 静态构建与 FPK 打包通过。

旧桌面自动同步依赖当前飞牛的本机 PostgreSQL 入口元数据结构；读取失败会停止相应操作并提示。完整 FPK 升级、完整卸载回退和其他飞牛版本仍需继续验证。

## 0.1.2 原生证书匹配与续期引用

- 使用飞牛证书模块的真实隔离测试复现：证书库存有泛域名证书，但未登记应用 SNI 时，应用地址仍收到主域名证书。
- 补充明确的应用 SNI 映射后，主域名及两个应用分别返回正确证书；以实际 SAN 校验主机名。
- 模拟证书原文件替换、续期生成新目录，以及飞牛主域名证书续期，均能更新证书引用。
- 停用时保留证书选择并关闭应用路由；移除时恢复原生映射来源，清理自有文件。
- 自动测试覆盖精确域名优先、通配符层级、有效期、错误库存、文件缺失、幂等、事务失败、崩溃恢复与外部修改保护。回退重载前先移除本次新建的配置片段，避免重新加载待撤销的路由。
- HTTP/HTTPS、IPv4/IPv6、Range、流式上传、双向 Upgrade 的原生隔离测试通过。
- 原生证书测试使用实际的 `www-data` 工作进程、私有应用状态目录和 Nginx 目录中的可读映射，覆盖原生模块的文件监听权限要求。
- 本机使用系统信任库严格校验证书链和域名：主域名、全部 17 个应用子域名及 FN Connect 均通过；DDNS-Go、Emby 首页返回正常响应。
- 比对更新前后状态：33 个业务容器的启动时间与重启计数保持不变，Nginx 主进程保持不变，飞牛原始证书库和映射内容保持不变；再次同步不重复改写配置。

本轮真机更新使用备份后原位替换应用二进制的方式；已构建 x86/ARM FPK，但未据此声称完整 FPK 升级流程已验证。

上述续期测试模拟证书库更新，不会向 CA 发起真实续期请求；不能替代未来到期时的实际续期验收。

## 0.1.3 网页图标与自定义代理

- 图标优先级：标签、本地文件、上传图标优先；仅未指定图标的应用尝试读取网页声明图标、favicon 和触摸图标。测试覆盖重定向、相对路径、ICO、HTTPS 后端、跨来源跳转限制和失败保留。
- 图标更新测试覆盖桌面与应用包根图标、缓存、外部修改保护和回退。真机现有 22 个入口已配置图标，更新后均保留原文件；17 个启用反代的入口不触发自动替换。另用真实 Emby 网页成功抓取声明的 PNG 图标，生成 64/256 像素图片。
- 控制面板支持后端地址覆盖、自定义位置、SSL 诊断和原始 Nginx 配置；表单校验错误在编辑区域显示并保留输入。
- 原生隔离集成测试覆盖自定义应用虚拟主机、根位置替换、自定义路径、请求头与查询转发、HTTP/HTTPS、IPv4/IPv6、Range、流式上传、双向 Upgrade，以及配置移除与停止时的 503。
- 自定义虚拟主机启用时，原生证书精确匹配、证书原文件替换和新目录续期引用测试通过。
- 真机通过控制面板临时保存 DDNS-Go 自定义配置：根位置和自定义路径均返回正常重定向并带测试响应头；向 HTTPS 端口发送 HTTP 时，`error_page 497` 正确重定向到 HTTPS。
- 故意提交原生 Nginx 不认识的指令时，保存返回 422，原设置和可用配置均恢复，其他应用继续正常。撤销临时配置后，自有虚拟主机文件及主配置 include 被清理，设置与测试前一致。
- 使用系统信任库严格校验证书链与域名：飞牛主页及全部 17 个应用路由通过。33 个业务容器的启动时间、状态及重启计数保持不变，Nginx 主进程未重启，飞牛原始证书库存与映射内容未变。
- `go test -race ./...`、`go vet ./...`、控制面板 JavaScript 语法检查、x86_64/ARM64 静态编译和 FPK 打包通过；源码及安装包递归隐私扫描通过。

本轮真机验证使用备份后更新已安装应用二进制的方式。完整 FPK 升级、ARM 飞牛硬件、桌面浏览器缓存刷新和任意第三方自定义 Nginx 指令组合仍需在相应环境验证。自动抓取暂不解码 SVG；没有可用栅格图标时保留原图标。SSL 申请与自动续期仍由飞牛管理。
